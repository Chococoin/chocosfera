# Repositorio Oficial de Historia - Chocósfera

## 📖 Visión General

El repositorio oficial `chocosfera/historia-oficial` en GitHub es el punto de entrada a la Chocósfera. Contiene la historia canónica, los personajes del sistema, y sirve como base para todos los forks de los usuarios.

**URL**: `https://github.com/chocosfera/historia-oficial`

## 🎯 Propósito

- **Punto de Entrada**: Todos los personajes comienzan su historia aquí
- **Historia Canónica**: La narrativa oficial de la Chocósfera
- **Open Source**: Cualquiera puede fork y proponer cambios
- **Educativo**: Explica la mecánica y filosofía del proyecto
- **Inspiración**: Personajes sistema (Tony, Pipo, Kaoka) como ejemplos

### README.md

```markdown
# 🍫 Chocósfera - Historia Oficial

> *"Me llevé un trozo de esa sustancia aromática y oscura a la boca, y me vi envuelto en una magia que me trasladó a un mundo tan hermoso y colorido como desconocido."*

Bienvenido a la **Chocósfera**, un universo narrativo colaborativo donde cada persona puede crear su propio personaje, contar su historia, y contribuir a una narrativa compartida sobre el chocolate, la sostenibilidad y la aventura.

## ✨ ¿Qué es la Chocósfera?

La Chocósfera es un proyecto educativo que combina:
- 🎭 **Storytelling**: Crea personajes y escribe historias
- 💻 **Tecnología**: Aprende Git, HTML, CSS, JavaScript
- 🤝 **Colaboración**: Trabaja con otros mediante forks y PRs
- 🌳 **Sostenibilidad**: Conecta con la realidad del cultivo de cacao
- 🎓 **Educación**: Aprende mientras te diviertes

## 🚀 Cómo Empezar

1. **Regístrate** en [chocosfera.com](https://chocosfera.com)
2. **Fork este repo** automáticamente al crear tu cuenta
3. **Crea tu personaje** siguiendo el wizard
4. **Escribe tu historia** en Markdown o HTML
5. **Publica y comparte** con la comunidad
```

```markdown
Me encontré con un trozo de chocolate oscuro, brillante como una joya. Su aroma era diferente, más profundo, más misterioso. Sin pensarlo dos veces, me llevé un pedazo a la boca.

Un mundo lleno de árboles de cacao gigantes, ríos de chocolate fluido, montañas de cacao en polvo. El cielo tenía un tono caramelo, y las nubes parecían algodón de azúcar.

¿Qué harás ahora que estás aquí?
```

## 🔄 Flujo de Actualización

### Commits en Historia Oficial

Cada commit importante sigue este formato:

```
<type>(<scope>): <subject>

<body>

<footer>
```

**Ejemplos**:
```
feat(tony): add new adventure in chocolate mountains

Tony discovers a hidden valley where ancient cacao trees grow.
This adds depth to his character and introduces new locations.

Closes #42
```

```
docs(guides): update HTML tutorial with new examples

Added interactive examples for CSS grid layout.
Improved accessibility sections.
```

### Pull Requests de la Comunidad

Los usuarios pueden proponer:
1. Nuevas aventuras para personajes sistema
2. Mejoras a la documentación
3. Nuevas locaciones en la Chocósfera
4. Correcciones de ortografía/gramática
5. Recursos educativos adicionales

**Proceso de Aprobación**:
1. PR es revisado por mantenedores
2. Se verifica que no rompa la narrativa canónica
3. Se verifica calidad del contenido
4. Se valida que sea apropiado para todas las edades
5. Merge y se convierte en canónico

## 🎨 Guías de Estilo

### Para Markdown
- Usar headers jerárquicos (h1 → h2 → h3)
- Párrafos cortos y legibles
- Usar énfasis (`*` y `**`) para destacar
- Incluir imágenes con alt text
- Código en bloques con sintaxis highlight

### Para Historias
- Mantener tono apropiado para todas las edades
- Promover valores positivos
- Incorporar elementos educativos sobre cacao/sostenibilidad
- Respetar la narrativa canónica establecida
- Ser creativo pero coherente

### Para Código HTML/CSS/JS
- Código limpio y comentado
- Accesibilidad (ARIA labels, semantic HTML)
- Responsive design
- Sin dependencias externas innecesarias
- Validar con W3C
